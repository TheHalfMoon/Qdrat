# Qdrat — Source Authorization Register

## Purpose

This file records source-use authorization provided by the Qdrat founder for the repositories and organizations listed below. It is part of Qdrat's provenance record and must travel with any future donor-code intake evidence.

## Founder authorization statement

The Qdrat founder has explicitly stated that Qdrat has permission to copy and use the complete source code from every source listed in this register for the purpose of building Qdrat.

Authorization source: founder statement in the project conversation on 2026-09-11.

Authorization status: `FOUNDER_ATTESTED`.

This register records the founder's authorization claim. It does not independently verify the scope of any private agreement and does not erase third-party copyright notices, dependency licenses, contributor rights, patent terms, trademarks, attribution requirements, or file/directory-specific license conditions already attached to source code. Any imported file must retain required notices and provenance unless a separate written grant explicitly removes those obligations.

## Intake rule

Founder authorization permits evaluation and planned source intake. Before a file is copied into Qdrat, record: source repository, exact commit/tag, source path, destination path, observed license, notice obligations, material modifications, security review, and reviewer. Mixed-license repositories require path-level qualification.
