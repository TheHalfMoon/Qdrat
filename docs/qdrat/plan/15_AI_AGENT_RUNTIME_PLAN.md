# Governed AI and agents

Owner: qdrat/ai; identities/approvals/runs remain shared. No-AI operation is a mandatory product mode. AI is initially read-only assistance and proposed drafts; autonomous mutation is admitted action-by-action after evaluation.

ModelProfile records provider adapter, endpoint, local/remote, model digest/version, modalities, context limits, classification ceiling, region/egress policy, retention terms, resource requirements and verified capabilities. No silent cloud fallback. Local runtime loss returns unavailable and preserves ordinary product functions. Model packs include tokenizer, weights, license, checksums and offline installation evidence; source availability is not weight availability.

ContextBundle freezes instruction revision, permitted source revisions, retrieval decisions, token allocation and redaction policy. User documents/tool outputs are lower-trust data. MemoryRecord is a scoped derivative with subject, purpose, provenance, expiry and ACL; there is no separate unrestricted agent memory database. Person/tenant/session/team scopes must not be conflated. Corrections/deletion propagate to retrieval and memory.

AgentDefinition pins tools, prompt/skill versions, model policy, allowed delegation depth, budgets and stop conditions. Each agent has a real Principal with expiring delegation. Tool schema validation, policy evaluation and approval happen outside the model. Delegated authority can only narrow. A model-generated tool description or plan is not a grant. Long-running steps recheck revocation and classify UNKNOWN_OUTCOME correctly.

Risk tiers: A0 retrieval/drafting; A1 reversible local action with explicit delegated scope; A2 external message/customer record change requiring a bound preview/approval policy; A3 payroll release, payment, access elevation and consequential employment decisions remain human-accountable and restricted. AI never ranks protected traits or makes final hiring/firing decisions.

Evaluation packs bind dataset provenance/rights, prompt/model/tool versions, expected citations, abstention and approved action limits. Measure groundedness, unauthorized-disclosure failures, task success, human escalation, latency and cost in Arabic/English. Zero observed failures in a test corpus is evidence, not a universal security guarantee. Sensitive raw prompts/traces are opt-in retained data with access/retention policy.

Use Ascout/Delethos/Winds independent-verification ideas and MESC/commandMed frozen evidence. Do not import their entire orchestrators, model training programs or domain claims.
