# Supply chain and source intake

Research classification and actual code intake are different records. Founder-authorized sources may be studied/used without routine reapproval. Preserve third-party notices and path-level obligations; a private grant is not evidence that every dependency has identical terms. Newly discovered public sources use their public licenses.

SourceIntake manifest requires repository, exact commit/tag and artifact digest, selected paths, destination paths, classification, license/grant basis, notices, dependency/weight/font/asset inventory, modifications, security/privacy review, tests, upgrade owner, replacement contract and disappearance fallback. “NOASSERTION” is unknown/mixed metadata, not a permissive license. No new donor code is imported in this plan.

Preferred choices: adapt authority/evidence patterns from founder sources; keep inherited Horilla notices/history; qualify small libraries or isolated optional services. No whole donor application becomes a Qdrat subsystem. Copying even a permissive component creates an ongoing patch/upstream-diff obligation.

G0 creates platform-specific hash-locked Python requirements and wheel manifest while preserving source requirement intent, exact base image/distro package evidence and model-wheel digest. Node/Rust/OS artifacts, locale/fonts, browser binaries and optional model packs enter the same inventory when introduced. SBOM covers images and vendored/copied files, not only package manifests. Offline vulnerability advisory data includes publication/freshness date; stale data is explicitly reported.

CI actions and release tools pin immutable revisions. Dependency updates use bounded PRs with affected contracts/tests, notice delta and upgrade/rollback evidence. Never execute donor install scripts during research. Builds separate networked acquisition from offline installation; release artifacts are signed by a trusted release workflow/identity outside untrusted PR control.

Cosign with customer-managed keys/offline verification and TUF-style version/expiry/rotation metadata are qualification candidates. Do not make public Fulcio/Rekor/OIDC mandatory for air-gap. Syft is the first SBOM tool candidate. Archived/unmaintained sources have explicit support/removal decisions.

For runtime source candidates, qualification happens before intake, not deferred until after shipping. Candidate absence must leave the related optional capability disabled, with a tested base-product fallback.
