# Founder GitHub intelligence

The connected repository listings returned **36 distinct repositories**, including **7 private**, with no additional repositories on the next page. Both owner and owner/collaborator/organization-member views were checked; the latter added wepld/wepld. “All accessible” means this installation's observable scope, not a claim about repositories it cannot list.

For each repository, metadata, branch inventory, default tree and available README were retrieved. All default trees were complete, except the explicitly empty Trcel repository has no commit/tree. Open PR metadata and head refs were enumerated. Twenty-four targeted implementation/specification files were read across the useful portfolio. No donor program or test suite was executed. Thousands of historical branch bodies were not exhaustively reviewed; active PRs are leads, not evidence that a design has shipped.

Evidence is in evidence/founder-inventory.json. It contains exact refs, sampled source blobs, manifest/test paths and active PR heads. Raw private source snapshots remain outside the public plan; the plan records provenance and architectural conclusions.

- Zyara shows transactional outbox/inbox patterns; Qdrat must independently specify tenancy and recovery.

- Ascout, Winds, Delethos, wePLD, SpecGrain and Diffcipline inform independent exact-revision evidence and bounded change governance.
