# Jobs, competitive assessment and Qdrat response

This matrix connects the primary evidence in chapter 04 to architecture and task decisions. “Strong reference” is a documented pattern, not a hands-on UX score. Complexity/administration assessments are engineering judgments about adopting that pattern. API maturity means the documented interface class; customer access and behavior still require connector conformance. All native surfaces use the same ObjectRef, C02 policy, C03 evidence and C05 execution contracts.

## Explicit exclusions

Public advertising technology, arbitrary employee surveillance, autonomous high-impact employment decisions, a public-cloud fleet control plane, a full office-suite clone, hardware MDM agent, bank settlement network and a general browser/desktop OS are INTENTIONAL_NON_GOAL for the initial product. Existing providers may be connected where a scoped customer job needs them. Automatic provider fallback that changes data residency, guessed payroll law and unrestricted formula execution are REJECT.

Feature parity is judged by successful end-to-end jobs and recoverability, not visual similarity. Migration acceptance includes IDs, attachments, comments, timestamps, permissions and business totals; a imported record count alone is insufficient. Missing API access never grants permission to scrape or impersonate a user.
