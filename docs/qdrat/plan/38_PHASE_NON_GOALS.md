# Phase boundaries and non-goals

G0 proves inherited engineering truth. No new suite, frontend rewrite, payroll behavior change or dependency modernization unrelated to reproducibility. G1 adds foundations with one protected journey, not a universal low-code platform. G2/G3 implement bounded connector/execution contracts before mass connector catalogs. G4 delivers a coherent People core; G5 alone can qualify Saudi live payroll.

Work/Service and commercial suites arrive through separate gates. Native accounting, CPQ, global payroll, manufacturing/MRP, insurer claims, clinical decisions and other industry engines require explicit later specifications and country/domain qualification. Their jobs can be connected before native replacement. “Everything operable” does not mean “everything owned by a new Qdrat engine”.

No mandatory public cloud, managed Qdrat control plane, paid model, graph database, vector server, Kafka, Kubernetes, Temporal, external IdP or analytics service in the baseline. Existing dependencies can remain until evidence supports removal. Do not replace them merely to satisfy a component-count target.

No unrestricted EAV for typed core, raw SQL mutation from Studio, arbitrary code in formulas, global agent administrator, hidden telemetry, implicit remote fallback, unbounded browser/GUI agents, silent background recording or autonomous consequential employment decisions.

No assurance that source grants erase transitive rights. No claim that package metadata equals file-level clearance. No claim that a docs page, README or unit test proves production reliability. No fake PASS, no fabricated SHA, no skipped required check relabeled as success.

Far-horizon specifications remain SHAPED and are refined against the real code at their frontier. Structural architecture changes require an ADR and affected-task invalidation. This is deliberate SpecGrain rolling-wave discipline, not permission for Muse to improvise a different architecture.
